# Tally Workspace Context

This prompt is loaded automatically for all Tally development work. It provides the current codebase state as a baseline for new feature requests.

## Current Status

**Tally** is a personal budget envelope app (React + .NET 10 + SQLite) with two parallel data systems:

### Path 1: PrototypeState (JSON blob, main app)
- Stores user data in `budget_accounts` table
- Managed by `PrototypeController` (`GET/PUT /api/prototype?username=`)
- Used by: Dashboard, Categories, Transactions, Inbox, Transaction Review, Settings
- TypeScript type: `PrototypeState` in `frontend/src/types/budget.ts`

### Path 2: Real EF Tables (beta only)
- `BudgetCategory`, `Transaction`, `BudgetProfile` DbSets
- Used only by "Live Data (beta)" view
- Controllers: `BudgetSetupController`, `TransactionsController`, `CategoriesController`

## Key Files

**Frontend (React + TypeScript):**
- `frontend/src/App.tsx` — Main app routing, views
- `frontend/src/types/budget.ts` — PrototypeState type definition

- `backend/Controllers/PrototypeController.cs` — Path 1 (JSON blob) API
